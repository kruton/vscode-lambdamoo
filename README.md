# LambdaMOO Language Support

LambdaMOO Language Support is a Visual Studio Code extension for editing LambdaMOO (`.moo`) source files, powered by a language server and Tree-sitter grammar.

## Installation

Open the **Extensions** view in Visual Studio Code, search for **LambdaMOO Language Support**, and select **Install**. You can also install it from the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=kruton.vscode-lambdamoo).

## Related projects

- [kruton/moo-lsp-rs](https://github.com/kruton/moo-lsp-rs) — the LambdaMOO language server
- [kruton/tree-sitter-lambdamoo](https://github.com/kruton/tree-sitter-lambdamoo) — the LambdaMOO Tree-sitter grammar
